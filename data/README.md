# Data Folder

This folder contains `final_features.csv`, the cleaned and feature-engineered
dataset used by `app.py`. It is small enough to commit directly to GitHub.

The two **raw** Kaggle source files — `application_record.csv` and
`credit_record.csv` — are **not** included in this repository because they
are large and freely available from Kaggle. To reproduce the full notebook
from scratch, download them from:

https://www.kaggle.com/datasets/rikdifos/credit-card-approval-prediction

and place both files in this `data/` folder before running
`notebooks/credit_card_analysis.ipynb`.
